# 功能概览

## 登录与退出

- 登录窗体自动识别角色，登录后进入对应界面；主界面右上角“退出登录”返回登录页，关窗即退出程序
- 登录页支持读者自助注册；两种角色都可通过“修改信息”改姓名/电话/邮箱和密码；管理员可一键重置读者密码

## 图书管理员端（5 个页签）

- **统计总览**：8 张数量卡片（图书种类、馆藏总册数、在库/已借出册数、读者数、未还记录、逾期记录、累计借阅）＋按分类的库存统计表
- **图书管理**：增删改查，支持按书名/作者/ISBN/出版社模糊搜索和分类筛选；有未归还册数的书不允许删
- **读者管理**：读者增删改查、查看每人当前在借数量
- **借阅管理**：办理借书（选读者选图书，自动校验）、办理还书、续借
- **借阅历史**：全部读者的借阅流水，可按全部/未归还/已归还/逾期筛选

## 借阅人端（3 个页签）

- **图书查询**：搜索图书并直接借阅（自动校验库存、可借上限、重复借阅）
- **我的借阅**：显示“在借 x 本，还可借 y 本”，支持续借和归还
- **借阅历史**：个人全部借阅记录及状态

## 内建规则

- 借期 30 天，每本最多续借 2 次，逾期按天计算并以红色标注
- 数据全部持久化到程序目录的 `library_data.xml`（无需安装数据库，删掉该文件即可重置为示例数据）
